
# Healthcare Admissions Analysis

Analysis of a synthetic hospital admissions dataset (55,500 raw rows, 54,860 after cleaning) to explore admissions, length of stay and billing.

## Files
- healthcare_analysis_cleaned.xlsx: cleaned data, analysis sheet and cleaning log
- healthcare_dataset_clean.csv: cleaned dataset
- healthcare_queries.sql: 8 SQL business questions
- PowerBI_dashboard_: dashboard build specification
- healthcare Admissions analysis reporting 
## Cleaning summary
- Fixed name casing and hospital name formatting
- Removed 534 exact duplicate rows
- Removed 106 negative billing rows
- Added Length_of_Stay and Age_Group

## Note
The data is synthetic, so the patterns in it are not real healthcare findings.
